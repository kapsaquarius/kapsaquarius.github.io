# Personal Portfolio Website

A modern, responsive portfolio website showcasing my professional journey, technical expertise, and project accomplishments.

## Features

- **About Me** - Professional background and expertise
- **Technical Skills** - Programming languages, frameworks, and tools
- **Projects & Publications** - Software development and research work  
- **Certifications** - Professional credentials and achievements
- **Interactive Design** - Smooth animations and responsive layout

## Built With

- **Frontend:** HTML5, CSS3, JavaScript
- **Framework:** Bootstrap 5
- **Animations:** AOS (Animate On Scroll)
- **Icons:** Bootstrap Icons, Boxicons
- **Deployment:** GitHub Pages
